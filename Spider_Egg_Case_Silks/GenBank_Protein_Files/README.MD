# Text Files with GenBank Protein Search

When searching [GenBank](https://www.ncbi.nlm.nih.gov/genbank/) Search of 'Protein': I looked for all proteins related to spider egg case silks/spidroins.  There are a ton of common terms used for various spider egg case silks (e.g., Tubuliform/Cylindriform (TuSp/CySp), Aciniform (AcSp), Egg Case Proteins, etc.).
The text files does NOT represent all spider egg case silks/spidroins.  Instead it's just the subset that are of particular interest to our experimental research on spider species we have studied.

The top line of each text file gives the website where all the information from GenBank is provided.  The text file includes the title, genbank ID, LOCUS, DEFINITION, ACCESSION, and VERSION.  Then some files further includes the TITLE, JOURNAL, and PUBMED.  Most importantly, at the bottom of each text file is a copy of the FASTA.
